# 공정 N빵 정산기

총무가 품목과 "지우 술 안 마심, 민수 10시에 감" 같은 상황을 입력하면 회식비를 나눠 주는 멀티 에이전트 정산기입니다.
계산 기준은 **금액을 보기 전에 그 자리에서 손을 들어** 정하고, 총무가 득표 수를 입력합니다.
결과는 **득표 수, 각자의 계산 근거, 송금표와 함께 Discord로** 공유합니다.

> 돈 계산과 표 집계는 코드가, 품목과 사람 말의 해석과 투표 안내는 에이전트가 맡습니다.

## 사용 방식

1. 총무가 앱(Streamlit, 로컬 실행)에 품목과 상황을 입력합니다.
2. 애매한 품목은 앱이 질문합니다 (예: "모둠세트 A에 소주 포함?").
3. 앱이 보여 주는 질문을 총무가 읽고, 손든 사람 수를 입력합니다.
4. Discord에 미리보기가 올라오면, 참석자 과반이 찬성할 때 확정합니다.

## 공정성 원칙

1. 기준은 금액을 보기 전에 투표로 정하고, 결과를 본 뒤에는 바꾸지 않는다.
2. 개인 조건(많이 먹음 등)은 본인 신고로만 반영한다. 다른 사람을 지목하지 않는다.
3. 증거(품목, 시간, 술 여부, 본인 신고)가 있는 조건만 반영한다.
4. 모두가 자기 금액의 계산 근거를 볼 수 있다.
5. 같은 입력이면 같은 결과가 나온다 (계산은 코드가 한다).
6. 누군가의 금액이 바뀌면, 전원의 금액 변화를 함께 보여 준다.
7. 총무의 입력(득표 수, 조건)도 결과와 함께 공개한다.
