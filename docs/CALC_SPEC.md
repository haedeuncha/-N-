# 계산 명세 — 공정 N빵 정산기

> 계산기(`calculator`)와 송금 정리(`settler`)가 따르는 규칙입니다. **여기 있는 숫자 예시가 테스트의 정답입니다** ([TEST_PLAN](TEST_PLAN.md) T-CALC).
> 계산은 모두 코드가 하고, LLM은 관여하지 않습니다.
> 관련 문서: [PLAN 8장](PLAN.md#8-계산-규칙) · [VOTING_SPEC](VOTING_SPEC.md)

## 1. 입력

| 입력 | 내용 | 정하는 곳 |
|---|---|---|
| 품목 `Item` | 이름, 가격, 분류(`food` / `drink` / `alcohol`), 차수, 주문 시각(선택) | 품목 해석(`item_reader`) 후 총무 확인, 또는 직접 입력 |
| 차수 `Round` | 시작·끝 시각 (τ 계산용), 할인·쿠폰 금액, **결제자별 결제 금액** (합계 = 그 차수 결제 총액) | 할인은 품목 해석 후 총무 확인. 시각과 결제자는 상황 파악 후 총무 확인. **결제 총액은 총무가 카드 영수증을 보고 입력**(영수증 사진이 있으면 그 총액으로 미리 채움). 결제자가 1명이면 그 사람 결제 = 결제 총액, 여러 명이면 총무가 사람별 금액을 입력 |
| 참석자 `Person` | 이름, 참석 차수, 술 여부, 도착·떠난 시각, 많이 먹음(본인 신고) | 상황 파악 + 총무가 읽어 주고 확인 |
| 기준 `Rules` | 술값, 일찍 간 사람, 가중치, 할인, 끝전 | 기준 투표 |

- 분류 `drink`(음료)는 계산에서 `food`와 똑같이 다룹니다.
- 금액은 모두 **원 단위 정수**로 입력합니다. 중간 계산은 분수(`fractions.Fraction`)로 해서 반올림 오차를 없앱니다.

## 2. 기호

| 기호 | 뜻 |
|---|---|
| *wᵢ* | 많이 먹음 가중치. 기본 1, 기준 투표 결과에 따라 1.2 또는 1.5. **음식·음료에만** 적용 |
| *τᵢ* | 시간 계수. "시간 비례"면 (머문 시간 ÷ 그 차수 전체 시간), 아니면 1 |
| *Aᵣ* | 차수 *r*에 참석한 사람 |
| *Dᵣ* | 차수 *r*에 참석한 사람 중 술 마신 사람 |

## 3. 계산 순서 (차수마다)

1. **품목별로 나눌 사람을 정합니다.**
   - 음식·음료: *Aᵣ*
   - 술: 기준이 "마신 사람만"이면 *Dᵣ*, "전원"이면 *Aᵣ*
   - 기준이 "떠나기 전 주문까지만"이면, 주문 시각이 그 사람이 떠난 시각 이후인 품목에서 그 사람을 뺍니다. 주문 시각이 없는 품목은 빼지 않습니다.
2. **품목별로 비율대로 나눕니다.**
   - 음식·음료: *wᵢ × τᵢ* 비율
   - 술("마신 사람만"이든 "전원"이든): *τᵢ* 비율 (가중치 *wᵢ*는 적용하지 않음)
3. **할인을 뺍니다.**
   - "비율대로"면 할인 전 부담액 비율대로, "똑같이"면 *Aᵣ*에게 똑같이 뺍니다.
4. **끝전을 처리합니다.**
   - 사람별 금액을 100원 단위로 내림합니다.
   - 차수 결제 총액과의 차이(끝전)는 그 차수 결제자가 부담합니다. 결제자가 여러 명이면 가장 많이 낸 사람이 부담합니다.
   - 기준이 "무작위"면 정산 ID를 시드로 한 명을 뽑아 부담시킵니다. 다시 계산해도 같은 사람이 나옵니다.
5. **차수별 금액을 사람별로 더합니다.**

## 4. 송금 정리

1. 사람별 잔액 = 낸 돈(모든 차수의 `payments` 합) − 낼 돈. 양수면 받을 사람, 음수면 보낼 사람입니다.
2. 보낼 금액이 가장 큰 사람과 받을 금액이 가장 큰 사람을 짝지어 송금하고, 이를 반복합니다.
3. 결과는 "민수 → 해든 22,000원" 형식의 목록입니다. 송금 횟수는 최대 (인원 − 1)회입니다.

## 5. 근거 문장 (`breakdown`)

사람마다 아래 형식으로 만듭니다. 모든 금액은 계산 결과에서 그대로 가져옵니다.

```
민수 22,000원
- 1차 음식·음료 80,000원 중 14,545원 (2시간/3시간 참석)
- 1차 술 30,000원 중 7,500원 (술 마신 3명, 2시간/3시간 참석)
- 끝전 내림 −45원
```

Discord 메시지에는 한 줄로 줄여서 보냅니다 (형식: [AGENTS 6장](AGENTS.md#discord-메시지-형식)). 예: `민수 22,000원 = 음식 14,545 (2/3시간) + 술 7,500 (2/3시간) − 끝전 45`

## 6. 숫자 예시

### 공통 상황: 1차 삼겹살집 (결제자 해든, 110,000원)

| 품목 | 가격 | 분류 | 주문 시각 |
|---|---:|---|---|
| 삼겹살 4인분 | 64,000 | food | — |
| 된장찌개 | 8,000 | food | 21:30 |
| 공기밥 4개 | 4,000 | food | — |
| 소주 4병 | 20,000 | alcohol | — |
| 맥주 2병 | 10,000 | alcohol | 21:30 |
| 콜라 2병 | 4,000 | drink | — |
| **합계** | **110,000** | 음식·음료 80,000 / 술 30,000 | |

| 참석자 | 시간 | 술 | 낸 돈 |
|---|---|---|---:|
| 해든 | 19:00~22:00 | ✓ | 110,000 |
| 민수 | 19:00~**21:00** (1시간 일찍 감) | ✓ | 0 |
| 지우 | 19:00~22:00 | **✗** | 0 |
| 서연 | 19:00~22:00 | ✓ | 0 |

### E1. 기본값 (술은 마신 사람만, 시간 비례, 가중치 없음)

- **음식·음료 80,000원**
  - 비율: 해든 1, 민수 2/3, 지우 1, 서연 1 (합 11/3)
  - 1단위 = 21,818.18원
- **술 30,000원**
  - 마신 사람끼리 나눠요. 비율: 해든 1, 민수 2/3, 서연 1 (합 8/3)
  - 1단위 = 11,250원

| | 음식·음료 | 술 | 합계(정확) | 100원 내림 | **최종** |
|---|---:|---:|---:|---:|---:|
| 해든 | 21,818.18 | 11,250 | 33,068.18 | 33,000 | **33,200** (끝전 +200) |
| 민수 | 14,545.45 | 7,500 | 22,045.45 | 22,000 | **22,000** |
| 지우 | 21,818.18 | 0 | 21,818.18 | 21,800 | **21,800** |
| 서연 | 21,818.18 | 11,250 | 33,068.18 | 33,000 | **33,000** |
| 합계 | 80,000 | 30,000 | 110,000 | 109,800 | **110,000** |

**송금:** 민수 → 해든 22,000 · 지우 → 해든 21,800 · 서연 → 해든 33,000

### E2. 술값을 "전원"으로 바꾸면

110,000원 전체를 비율 1 : 2/3 : 1 : 1로 나눠요. 1단위는 30,000원이에요.

| | E1 | E2 | 변화 |
|---|---:|---:|---:|
| 해든 | 33,200 | 30,000 | −3,200 |
| 민수 | 22,000 | 20,000 | −2,000 |
| 지우 | 21,800 | 30,000 | **+8,200** |
| 서연 | 33,000 | 30,000 | −3,000 |

> 이 표는 원칙 P6(누가 차액을 떠안는지 전원에게 보여 준다)을 보여 주는 예시예요. 조율 Agent가 대안을 제시할 때 이 형식을 씁니다.

### E3. 일찍 간 사람을 "똑같이"로 바꾸면

- 음식·음료 80,000원은 4명이 20,000원씩 내요.
- 술 30,000원은 마신 3명이 10,000원씩 내요.

| 해든 | 민수 | 지우 | 서연 |
|---:|---:|---:|---:|
| 30,000 | 30,000 | 20,000 | 30,000 |

### E4. 일찍 간 사람을 "떠나기 전 주문까지만"으로 바꾸면

21:30에 주문한 된장찌개와 맥주는 민수가 빠져요. 이 기준에서는 *τᵢ* = 1이에요.

| 품목 | 나누는 사람 | 1인당 |
|---|---|---:|
| 삼겹살 + 공기밥 + 콜라 72,000 | 4명 | 18,000 |
| 된장찌개 8,000 | 해든, 지우, 서연 | 2,666.67 |
| 소주 20,000 | 해든, 민수, 서연 | 6,666.67 |
| 맥주 10,000 | 해든, 서연 | 5,000 |

| | 합계(정확) | 100원 내림 | **최종** |
|---|---:|---:|---:|
| 해든 | 32,333.33 | 32,300 | **32,500** (끝전 +200) |
| 민수 | 24,666.67 | 24,600 | **24,600** |
| 지우 | 20,666.67 | 20,600 | **20,600** |
| 서연 | 32,333.33 | 32,300 | **32,300** |

> 민수는 E1(시간 비례)에서는 22,000원, E4에서는 24,600원을 내요. 금액을 보기 전에 기준을 투표해야 하는 이유(P1)를 보여 주는 예시예요.

### E5. 서연 "많이 먹음" + 가중치 1.5배 (나머지는 기본값)

- **음식·음료**
  - 비율: 해든 1, 민수 2/3, 지우 1, 서연 1.5 (합 25/6)
  - 1단위 = 19,200원
- **술:** 가중치를 적용하지 않아서 E1과 같아요.

| | 음식·음료 | 술 | 합계(정확) | **최종** |
|---|---:|---:|---:|---:|
| 해든 | 19,200 | 11,250 | 30,450 | **30,500** (끝전 +100) |
| 민수 | 12,800 | 7,500 | 20,300 | **20,300** |
| 지우 | 19,200 | 0 | 19,200 | **19,200** |
| 서연 | 28,800 | 11,250 | 40,050 | **40,000** |

### E6. 2차 호프 (해든·지우·서연, 결제자 서연, 쿠폰 −3,000)

| 품목 | 가격 | 분류 |
|---|---:|---|
| 치킨 | 20,000 | food |
| 생맥주 4잔 | 16,000 | alcohol |
| 사이다 | 2,000 | drink |
| 쿠폰 | −3,000 | 할인 |
| **결제** | **35,000** | |

- **할인 전 금액**
  - 음식·음료 22,000원 ÷ 3 = 7,333.33원
  - 술 16,000원 ÷ 2 = 8,000원
  - 결과: 해든 15,333.33원, 지우 7,333.33원, 서연 15,333.33원 (합 38,000원)
- **할인 3,000원:** 비율대로 빼요. 해든 −1,210.53원, 지우 −578.95원, 서연 −1,210.53원

| | 할인 후(정확) | 100원 내림 | **최종** |
|---|---:|---:|---:|
| 해든 | 14,122.81 | 14,100 | **14,100** |
| 지우 | 6,754.39 | 6,700 | **6,700** |
| 서연 | 14,122.81 | 14,100 | **14,200** (끝전 +100, 결제자) |

### E7. 1차 E1 + 2차 E6 합산과 송금

| | 1차 | 2차 | 낼 돈 | 낸 돈 | 잔액 |
|---|---:|---:|---:|---:|---:|
| 해든 | 33,200 | 14,100 | 47,300 | 110,000 | **+62,700** |
| 민수 | 22,000 | — | 22,000 | 0 | −22,000 |
| 지우 | 21,800 | 6,700 | 28,500 | 0 | −28,500 |
| 서연 | 33,000 | 14,200 | 47,200 | 35,000 | −12,200 |
| 합계 | 110,000 | 35,000 | 145,000 | 145,000 | 0 |

**송금 (3회):**
- 지우 → 해든 28,500
- 민수 → 해든 22,000
- 서연 → 해든 12,200

### E8. 술값 "전원" + 서연 가중치 1.5배 (나머지는 기본값)

가중치는 음식·음료에만 적용하고, 술은 전원이 *τᵢ* 비율(1 : 2/3 : 1 : 1)로 나눠요.

| | 음식·음료 | 술 | 합계(정확) | **최종** |
|---|---:|---:|---:|---:|
| 해든 | 19,200 | 8,181.82 | 27,381.82 | **27,600** (끝전 +300) |
| 민수 | 12,800 | 5,454.55 | 18,254.55 | **18,200** |
| 지우 | 19,200 | 8,181.82 | 27,381.82 | **27,300** |
| 서연 | 28,800 | 8,181.82 | 36,981.82 | **36,900** |
| 합계 | 80,000 | 30,000 | 110,000 | **110,000** |

### E9. 1차 결제자가 2명 (해든 60,000 · 서연 50,000, 기준은 E1)

- 끝전 200원은 **더 많이 낸 해든**이 부담해요. 그래서 1인당 금액은 E1과 같아요.
- 잔액: 해든 +26,800 · 서연 +17,000 · 민수 −22,000 · 지우 −21,800

**송금 (3회):** 민수 → 해든 22,000 · 지우 → 서연 17,000 · 지우 → 해든 4,800

## 7. 경계 사례

| 상황 | 처리 |
|---|---|
| 술 마신 사람이 0명인데 술 품목이 있음 | 계산하지 않고 확인 질문: "술을 마신 사람이 없는데 소주 4병이 있어요" |
| 떠난 시각이 도착 시각보다 빠름 | 입력 오류로 되돌림 |
| 떠난 시각이 없음 | 끝까지 있었던 것으로 봄 |
| 할인이 결제 전 금액보다 큼 | 입력 오류로 되돌림 |
| 참석자 1명 | 계산은 하지만 송금표는 비어 있음 |
| 결제자가 참석자 명단에 없음 | 입력 오류로 되돌림 |
